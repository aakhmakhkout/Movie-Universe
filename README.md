# 🎬 Movie Universe V2

A modern movie and series discovery platform built with **Next.js App Router** and **TMDB API**.

> 🚧 This project is currently under development. The section below documents the progress made throughout the project.

---

# 🛠 Tech Stack

- Next.js 16
- React 19
- Tailwind CSS
- TMDB API
- Lucide React

---
